# Canonical Records Context: Media Blitz Subsystem

Project Enki is the core coherence engine. Media Blitz is a downstream publishing product.

## Canonical Record Scope

Records such as:
- `records/artifacts/NKS-ART-000002-media-blitz-os-as-publishing-subsystem.md`
- `publishing/packages/NKS-PUB-000002-media-blitz-is-the-publishing-subsystem.md`
- related narratives, proofs, and visual requests

...correctly document that Media Blitz is a publishing subsystem consuming Enki's coherence engine.

These are **product-scoped canonical records**. They are not statements about the overall system identity.

When new canonical records are created, ensure:
1. Product-scoped records clearly reference Enki as the containing system
2. Enki-scoped records (coherence, reconciliation, governance) do not carry product-specific language
3. Consumer contracts establish the boundary between Enki and downstream products

## Historical Note

Early project records (Sprints 1–10, prior work items) refer to the system as "Media Blitz OS." This was the initial working title. The authoritative current system identity is **Project Enki**.
